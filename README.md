## 🚀 Proyectos destacados · Featured Projects

### 🧾 FacturaPro EC

Sistema de facturación e inventario para negocios ecuatorianos: punto de venta, compras, cuentas por cobrar, control de existencias, reportes y auditoría. Compuesto por una API en **Spring Boot** y un frontend **React + TypeScript**.

**Stack:** Java 21 · Spring Boot 3 · Spring Security · Spring Data JPA · Flyway · MySQL 8 · React 19 · TypeScript · Vite · Tailwind CSS

**Destacados:**
- Roles y permisos reales aplicados en el backend con `@PreAuthorize`, sesión con protección CSRF y bloqueo tras intentos fallidos
- Punto de venta con cálculo oficial de importes en el backend, numeración secuencial por año y comprobantes en PDF
- Inventario transaccional con bloqueo de filas, movimientos trazables y registro de auditoría inmutable
- Reportes de ventas, impuestos e inventario con exportación a CSV, más panel con indicadores

### 🛍️ DISTRICT 09

Demo de tienda streetwear **100% estática** (sin backend): catálogo, carrito con `localStorage`, búsqueda, detalle de producto y pedidos por WhatsApp. Funciona como demo de producto para marcas de ropa independientes.

**Stack:** HTML semántico · CSS puro (variables y animaciones) · JavaScript vanilla · CSP · Sin dependencias

**Destacados:**
- Catálogo validado y carrito persistente con `localStorage`, búsqueda y detalle de producto
- Cabeceras de seguridad (CSP) configuradas para Netlify, Cloudflare Pages y Vercel
- Diseño responsive con animaciones de entrada y soporte de `prefers-reduced-motion`
- Desplegada en línea y lista para personalizar con un cliente
